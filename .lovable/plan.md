# Reframe the site as pre-launch

## Goal
Keep the current design and functionality, but rewrite public-facing language so Sieve Capital is consistently presented as a firm and platform in development—not an operating business with live clients, infrastructure, certifications, or proven results.

## Changes
- Rewrite homepage headlines, metrics, feature descriptions, sample feeds, performance language, and access messaging in future-tense or clearly labelled illustrative terms.
- Update Research, Technology, API, and About pages so publications, infrastructure, capabilities, offices, and market access are described as planned, proposed, or being developed.
- Remove or qualify unsupported operating claims such as AUM coverage, existing clients, live data, exchange memberships, registrations, SOC 2 certification, production latency, and historical performance.
- Preserve the certificate verification and administration feature as a working website utility, while avoiding claims that certificates already exist unless a matching registry record is found.
- Align SEO descriptions and social metadata with the pre-launch positioning while keeping the browser tab title as “Sieve Capital.”

## Validation
- Search the full public site for remaining present-tense operating claims.
- Check every public page in the browser for layout issues, misleading copy, and console errors.
- Confirm the preview build completes successfully.
